## Appointment Form

Formulario web responsivo para **programar citas** en una clínica. Este proyecto está diseñado con HTML y CSS, enfocado en accesibilidad, estética profesional y facilidad de uso.

---

### Propósito del proyecto

Crear una interfaz clara y funcional que permita a los pacientes ingresar sus datos personales y detalles de la cita, con opciones para enviar o cancelar la información.

---

###  Estructura del proyecto

-  [`index.html`](https://github.com/ALEXANDER242164/OOP/blob/ronnieSE/frontend/Appointment%20Form/index.html): Contiene la estructura del formulario, incluyendo campos como nombre, apellidos, teléfono, correo, fecha, hora, motivo y comentarios.
  
-  [`style.css`](https://github.com/ALEXANDER242164/OOP/blob/ronnieSE/frontend/Appointment%20Form/style.css): Define el diseño visual del formulario, incluyendo fondo con imagen clínica, contenedor flotante, botones estilizados y diseño responsivo.
  
- [`Documentation HTML.md`](https://github.com/ALEXANDER242164/OOP/blob/ronnieSE/frontend/Appointment%20Form/Documentation%20HTML.md): Explica detalladamente la estructura y propósito del archivo HTML.
  
-  [`Documentation CSS.md`](https://github.com/ALEXANDER242164/OOP/blob/ronnieSE/frontend/Appointment%20Form/Documentation%20CSS.md): Describe los estilos aplicados, su función y cómo se adaptan a distintos dispositivos.

---

###  Tecnologías utilizadas

- **HTML**: Lenguaje de marcado utilizado para definir la estructura semántica y el contenido del formulario.
  
- **CSS**: Lenguaje de hojas de estilo empleado para el diseño visual, la adaptación responsiva y la optimización de la experiencia de usuario.
  
- **Visual Studio Code**: Editor de código fuente utilizado como entorno de desarrollo para la creación, edición y mantenimiento del proyecto.
  
- **Media Queries**: Herramienta de CSS que permite adaptar el diseño y la disposición de los elementos a distintos tamaños y resoluciones de pantalla.
  
- **YouTube**: Principal fuente de consulta para la comprensión y aplicación de conceptos relacionados con el desarrollo web.
  
- **Inteligencia Artificial (IA)**: Recurso de apoyo empleado para la generación de contenido, resolución de dudas y mejora del desarrollo del proyecto.

---

### Características destacadas

- Diseño centrado y flotante con fondo clínico.
- Scroll personalizado dentro del formulario.
- Validación básica de campos (email, teléfono, campos obligatorios).
- Botones diferenciados para enviar y cancelar.
- Adaptación automática a dispositivos móviles.

---

### Pasos para visualizar la pagina

1. Clona el repositorio:  
   https://github.com/ALEXANDER242164/OOP/tree/ronnieSE/frontend/Appointment%20Form
