## 1. Descripción General del Lenguaje HTML

**HTML (HyperText Markup Language)** es el lenguaje estándar para crear la estructura y contenido de una página web.  Define los elementos visibles y su jerarquía, como títulos, párrafos, formularios, enlaces, imágenes, etc.

Este archivo construye una interfaz para **programar citas médicas** en la Clínica Salud.  
El contenido HTML define la estructura del formulario, mientras que el estilo visual proviene de un archivo externo CSS (`style.css`).

## 2. Estructura General del Documento
<!DOCTYPE html>
<html lang="es-MX">
  <head> ... </head>
  <body> ... </body>
</html>

#### 🔹 `<!DOCTYPE html>`

Indica al navegador que el documento sigue el estándar **HTML5**, garantizando compatibilidad moderna.

#### 🔹 `<html lang="es-MX">`

Etiqueta raíz que envuelve todo el contenido del sitio.  
El atributo `lang="es-MX"` define el idioma principal como español de México, útil para accesibilidad y SEO.
