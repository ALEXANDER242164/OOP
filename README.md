# 🚀implementacion de la agenda de citas


## descripcion
Api que permite agenda de pacientes y permite a un miembro del staff la cual es la secretaria administrar las citas de manera didactica y faccilmente.


## 📸 demo
estamos en la version pre-aplha del proyecto

## ✨ caracteristicas 
las caracteristicas que tendra esta rama es que en ella se subiran los archivos los cuales ya incluyen la implentacion del proeyecto, a lo que me refiero es que tendra el codigo que necesita el proyecto de la parte de backend, que es la formacion de la API, y la base de datos para que el proyecto pueda funcionar como tal para de esta manera tener lo mas organizado posible 

## 🛠️ tecnologias usadas en el proyecto
- swagger UI
- spring boot
- SOQL
- H2
- java
